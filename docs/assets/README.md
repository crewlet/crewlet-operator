# Brand assets

Illustrations and icons used by the README and the documentation. The
documentation site publishes this directory beside every version's pages, and
leaves this file out of them.

| File | Used for |
|---|---|
| `crewlet-icon.svg` | The Crewlet mark: the documentation index's header |

The mark is a copy of the
[Crewlet engine's](https://github.com/crewlet/crewlet/blob/main/docs/assets/README.md),
byte for byte, which takes it from the Crewlet design system: never redraw,
recolour or re-optimise it here. It is a Crewlet trademark, used here because
the operator is a Crewlet product; the Kubernetes logo is not ours to combine
with it.

The mark is traced from raster art and is **not** minified: at aggressive
settings `svgo` drops geometry from it.
